Vidra setup

    Welcome

    This wizard generates the environment file your deployment runs on, and can run the deploy for you. It is served by the vidra binary on this host's loopback interface, and it talks to nothing else.

    The admin account is not part of this file and cannot be. Once the stack is up, the api mints a one-time owner-claim token and prints it in its own log; the last step tells you how to redeem it.

    System check

    What this host looks like right now — the same checks vidra doctor runs, from files, the rendered compose model and the daemon.

    This is not a gate. A ✗ here does not stop the install: on a first install half of what doctor checks is about a deployment that does not exist yet. It is here so a Compose older than 2.24, or a disk with no room for the images, is something you read now rather than discover from a failed deploy.
